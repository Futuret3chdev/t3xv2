# T3X v2

Production clone base of the memetorrent-react site (from `Futuret3chdev/mt-ecosystem/memetorrent-react`).

Original systems left completely untouched so you can always revert.

This is the development base for the T3X network portal:
- Native T3X coin dashboard
- Staking portal
- User coin minting
- Genesis block creation and validation
- Transaction explorer

Built to integrate with the existing mt-core node style and the T3X Wallet.
